Summarise a context tree Bootstrap

``` r

summary(object, ...)
```

## Arguments

- ...:

  Ignored.

The per-pathway summary `data.frame` (`object$summary`); see
[`bootstrap_pathways`](https://pak.dynasite.org/transitiontrees/reference/bootstrap_pathways.md)
